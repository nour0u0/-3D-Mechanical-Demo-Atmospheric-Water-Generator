# Extracteur d’Eau Atmosphérique — Modèle 3D et Vidéo Explicative

## Présentation

Ce projet présente une visualisation 3D d’un **extracteur d’eau atmosphérique (AWE — Atmospheric Water Extractor)**, un système conçu pour extraire l’eau présente dans l’humidité de l’air.

Le projet a été réalisé avec **Blender** afin de représenter les différents composants du système et d’expliquer leurs rôles dans le processus d’extraction de l’eau.

## Contenu du projet

- **`montage.mkv`** — Vidéo explicative présentant les différentes parties de l’extracteur d’eau atmosphérique.
- **`project.blend`** — Fichier du projet Blender contenant le modèle 3D et la scène utilisés pour réaliser la visualisation.

## Principe de fonctionnement

Le système représenté dans ce projet repose sur les étapes suivantes :

1. **Admission de l’air :** l’air ambiant chargé d’humidité entre dans le système.
2. **Extraction de l’humidité :** un maillage soumis à une haute tension est utilisé pour favoriser la récupération de l’eau présente dans l’air. Selon le principe physique mis en œuvre, l’humidité peut être condensée en eau liquide ou captée par le maillage.
3. **Collecte de l’eau :** l’eau récupérée s’accumule dans le réservoir situé au bas du système.

Le fonctionnement exact dépend de la conception et du principe physique utilisés dans le dispositif présenté.

## Outils utilisés

- **Blender** — Modélisation 3D, préparation de la scène et réalisation de la vidéo explicative.

## Explorer le projet

### Visionner la vidéo

Ouvrir le fichier `montage.mkv` pour découvrir les différents composants de l’extracteur d’eau atmosphérique et comprendre leurs fonctions.

### Ouvrir le projet Blender

1. Installer [Blender](https://www.blender.org/download/).
2. Cloner ou télécharger ce dépôt GitHub.
3. Ouvrir le fichier `project.blend` dans Blender.
4. Explorer le modèle 3D, les objets, les matériaux et la configuration de la scène.

## Objectif du projet

L’objectif est de fournir une représentation visuelle et pédagogique d’un extracteur d’eau atmosphérique afin de faciliter l’identification et la compréhension de ses principaux composants.
